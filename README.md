# Botazzo.Net — Site Profissional

Site institucional para técnico de informática e desenvolvedor web.

## Estrutura

- `index.html` — página principal
- `portfolio.html` — portfólio de desenvolvimento web
- `assets/css/style.css` — estilos e responsividade
- `assets/js/script.js` — menu, animações, WhatsApp e efeitos
- `assets/img/` — imagens dos projetos



## Próximas evoluções

- painel administrativo;
- cadastro de portfólio;
- banco de dados;
- página individual para cada projeto;
- SEO avançado;
- Google Analytics;
- domínio e e-mail profissional.
